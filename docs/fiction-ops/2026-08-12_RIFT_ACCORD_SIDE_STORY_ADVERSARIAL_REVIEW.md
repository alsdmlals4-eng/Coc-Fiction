# Rift Accord 외전 적대적 검토 — 2026-08-12

## 범위
- 제156~161화 최종 집필본
- 최신 사용자 승인 보정 우선
- 중심: 협약 내용/긴장, 이안 실무축, 주안–앨리스 최소 관계 회수

## MUST_FIX — 수정 완료

### 1. 제4·5조가 제목만 있고 실제 협상 기능이 약함
- 문제: 9개 조항을 전면에 내세우면서 제4조(각성자 자율권)와 제5조(상호신고)가 목록 수준에 머무르면 협약이 부분적으로만 실재하는 느낌이 남음.
- 수정:
  - 제4조에서 `실명·현재 위치·능력 상세` 상시등록안과 자율권 충돌을 실제 협상으로 추가.
  - 식별코드·위험범주·자발적 투입범위·연락창구로 축소.
  - `등록은 징집동의가 아니다`를 조문 핵심으로 고정.
  - 제5조에서 과잉신고/무신고 양쪽 실패를 제시하고 즉시 경보와 상세보고를 분리.
  - 반복적 은폐·축소가 제6조 도전사찰 근거가 되게 연결.
- 회귀 확인: 제4·5·6조가 서로 독립 항목이면서도 신고→의심→검증으로 연결됨.

### 2. 라르고 `[규율]`이 회의 안전규칙을 스스로 위반하는 모순 가능성
- 문제: 회의장 내 초상능력 사용 금지 상태에서 라르고가 초상능력으로 상대를 제압하면 `합의한 규칙을 지키게 한다`는 payoff가 자기모순으로 보일 수 있음.
- 수정:
  - 개회 전 별도 안전규칙에 `규칙 위반을 중단시키기 위한 최소한의 제압`을 지정 안전담당자에게 허용.
  - 지정 안전담당자 = 라르고 휴빙.
  - 적용 범위는 위반 행동 중단으로 사전 공개, 구체 수단만 봉인 부속서로 둠.
  - 각 대표에게 부속서 열람권이 있었음을 명시.
  - `[규율]` 공개 뒤에도 표결·사상·협정 결론을 강제하지 못함을 장면으로 재확인.
- 회귀 확인: 이후 군이 `[규율]`을 협정 집행수단으로 쓰자고 제안하지만 앨리스/라르고가 거부. 협정 집행은 기록·검증 절차에 남음.

## SHOULD_FIX — 수정 완료

### 3. 제8조 명칭 변화가 애매할 수 있음
- 초기안은 `비상공동지휘안`, 실제 합의는 `비상공동목표체계`로 구분.
- 한 명의 지휘관이 서로 다른 초상전력을 직접 지휘하지 않고 공동 목표만 정하며 각 조직 지휘권은 유지.

## 공격 검토 결과

### 협약이 설정 설명회인가?
- PASS.
- 모든 핵심 조항에서 누군가 권한·비밀·기동성·독점권을 실제로 잃고, 수정안이 상태를 바꿈.
- 태평양 고정점 손실/안정도 하락이 시간압박으로 작동.

### 결렬 가능성이 실제인가?
- PASS.
- 가론 대표단 철수 경고와 우회술 지원 상실 가능성.
- 제7조 강경파의 회의장 규칙 위반.
- 제8·9조에서 동원권/탈퇴권 충돌.

### 이안이 카메오인가?
- PASS.
- 미스캐토닉 관리 실패 증거 제출, 제5조 신고구조, 제6조 입증의무/대체검증, 제9조 기록절차, 최종 공동보고서까지 실무 핵심 역할.
- 공식 대표/서명 책임은 브루스 매시에게 유지.

### 주안–앨리스가 협약을 잡아먹는가?
- PASS.
- 재회와 휴회 중 사과·고백만 처리.
- 즉답/연애 확정 없음.
- 결말도 `고백은 받음 / 화해는 시작 / 관계는 미정`으로 유지.

### 하템 환각이 새 정보를 제공하는가?
- PASS.
- 이안이 이미 관찰한 갈등만 재조합.
- `환각 재발. 신규 정보 없음.` 기록 명시.

### 다빈 `[잔재]`가 새 시간능력으로 비대해지는가?
- PASS.
- 선행감각은 실제 사건으로 확정되지 않으며 일부러 검증사고를 만들지 않음.

### 엘리엇 은검→메스가 주민 후계자 인증이 되는가?
- PASS.
- `귀속 미정`, `공동보관 유지`, `사용자 반응 미확정`을 유지.
- 의미해석과 관찰을 분리.

### DG가 과거 사건의 배후로 소급되는가?
- PASS.
- 없음. 대균열 전선 대응 주체로만 확장.
