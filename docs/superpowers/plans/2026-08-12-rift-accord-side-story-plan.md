# 《폭풍의 눈》 2부 외전 Rift Accord Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 제155화 직후부터 이어지는 제156~161화 외전을 집필해 2부의 인물 아크를 짧게 닫고, Rift Accord 협약의 실제 조항·검증·사찰·파기 위험·대균열 전선의 도덕적 타협을 작품 전체 최종 갈등으로 완성한다.

**Architecture:** 6화 구성. 제156화는 다빈·주민 후일, 제157화는 정상회의 집결과 주안·앨리스 재회, 제158~160화는 협정 협상과 결렬 위기 및 라르고 `[규율]` 최초 공개, 제161화는 불완전한 협약 체결과 다음 시대 진입으로 구성한다. 주안–앨리스는 화해·사과·고백까지만 수행하고 결과는 열린 결말로 남긴다. 이안은 브루스 매시의 공식 대표 기능을 침범하지 않으면서 미스캐토닉 실무 보좌·현장 마도사·금지지식 관리 실패 보고자로 협정 핵심 조항에 개입한다.

**Tech Stack:** 한국어 웹소설 원고, Coc-Fiction 최신 Canon/감사 문서, 원본 TRPG 로그, Base/프로젝트 fiction skills, python-docx, LibreOffice headless render QA.

## Global Constraints

- 최신 사용자 결정 > 원본/source log > 최신 외부 활성 원고 > GitHub 현행 production container > 구형 225화/legacy.
- 본편 화수는 되돌리지 않고 제156~161화로 이어간다.
- 앨리스 표기 사용. `엘리스`, `히템`, `버실라`, `바실라`, `Versilla`, `Woff`는 활성 외전 본문 금지.
- 다빈의 `[잔재]`는 확정 미래예지/자유로운 시간역행이 아니다.
- 엘리엇 은검의 메스 변화는 외전에서 최초 공개한다.
- 주안–앨리스는 짧은 화해·사과·고백만 하고 연애의 결과는 열린 결말로 둔다.
- 이안의 하템 환각은 이안이 모르는 신규 정보를 제공하지 않는다.
- 라르고의 `[규율]` 최초 실제 공개는 Rift Accord 회의 중 `회의 중입니다.` 장면이다.
- `[규율]`은 협상 결과를 강요하지 않고 합의된 회의 규칙을 폭력으로 깨지 못하게 하는 기능으로 사용한다.
- 외전의 중심은 협약: 조항, 이해관계, 검증, 사찰, 집행, 파기 위험, 관리된 묵인, 대균열/태평양 전선.
- 각 화 본문 2,000자 이상(공백 제외 목표), 기본 중앙 POV 1개와 필요 시 보조 POV 1~2개.
- DOCX 최종본은 렌더 후 모든 페이지를 육안 검수한다.
