# 《폭풍의 눈》 전역 복선–회수 Ledger — 2026-08-11

## 목적

1부 → 브리지/외전 → 2부 → Rift Accord의 장기 seed를 단순 재등장이 아니라 **의미 변화와 행동 변화까지 포함한 payoff**로 추적한다.

상태:

```text
SETUP
→ RECALL
→ RECONTEXTUALIZE
→ PARTIAL_PAYOFF
→ PAYOFF
→ AFTERMATH
```

모든 항목에 모든 단계가 필요한 것은 아니다. 하지만 **작품 중심축·장기 미스터리·관계 아크**는 `RECONTEXTUALIZE`와 `AFTERMATH`까지 확인한다.

판정:
- `GREEN`: 현행 구조가 이미 강함.
- `GREEN_AFTER_REWORK`: 위치는 좋고 P0/P1 재구축 뒤 강해짐.
- `DEBT`: 실제 회수 위치/원인이 아직 부족.
- `VERIFY_SOURCE`: 원본/정본 재확인 필요.
- `RIFT_PAYOFF`: 본편에서 닫지 않고 Rift Accord에서 닫음.
