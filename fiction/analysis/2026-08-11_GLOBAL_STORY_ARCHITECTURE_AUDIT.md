# 《폭풍의 눈》 전체 서사 구조 감사 — 2026-08-11

## 0. 범위와 권위

이번 감사는 2부만 분리하지 않고 **현재 외부 최신 원고 전체와 최신 사용자 Decision을 기준으로** 다음 구간을 한 흐름으로 본다.

```text
제1~44화: 1부 본편
→ 제45~66화: 1부 후일·호수가 보이는 마을·8년 브리지 기능
→ 제67~155화: 2부 본편 기능
→ 2부 외전 Rift Accord: 최종 관계/세계 확장 payoff
```

위 구분은 **서사 기능 분류**다. 현재 원고의 화수를 다시 매기자는 제안이 아니다.

권위 순서:

```text
최신 사용자 Decision
→ 실제 원본/source-log·원본사건감사
→ 외부 최신 활성 원고
→ GitHub 현행 production container
→ 구 225화 압축본·구형 bible·archive
```

GitHub의 과거 `1부 1~70 / 외전 90~95 / 2부 166~225` 번호는 historical storage topology로만 본다. 현재 서사 번호를 되돌리지 않는다.

감사 렌즈:

- `CHOICE_PROOF`
- `IDENTITY + COMPETENCE + COST + CHOICE + CONSEQUENCE`
- `WITHHOLD_INFORMATION_NOT_CONTEXT`
- `READER_KNOWLEDGE_MATRIX`
- `SETUP → RECALL → RECONTEXTUALIZE → PARTIAL_PAYOFF → PAYOFF → AFTERMATH`
- 중요 상대의 `own turn`, `SKILL / TACTIC / RULE / RELATION`

이번 문서는 구조 감사다. 본문 line edit는 아직 시작하지 않는다.

# 1. 전체 작품의 주제적 등뼈

현재 가장 강한 통합 질문은 다음이다.

> **사랑·보호·대의가 타인의 선택을 빼앗는 순간에도 선의라고 할 수 있는가?**

전체 사건은 서로 다른 규모에서 같은 질문을 반복한다.

| 구간 | 보호/선의의 주체 | 보호받는 사람 | 위험한 전환 |
|---|---|---|---|
| 1부 | 윌리엄 | 엘리스 | 사랑과 인류 보호가 당사자 선택보다 앞섬 |
| 1부 | 황색·히템/하템·밀리 일부 | 사람/인질/동료 | 사람을 목적·재료·필요한 자원으로 바꿈 |
| 1부 | 쇼거스·탈론 등의 완전성/사명 논리 | 세계/목표 | 하나의 정답이 사람보다 먼저 옴 |
| 브리지 | 외갑 | 조세이칸 | 보호 장치가 보호 대상의 의지보다 앞섬 |
| 브리지 | 가론 | 임무/조직 | 사람을 자산·최적해로 환산함 |
| 2부 | 엘리엇 | 다빈 | 미래를 안다는 이유로 선택을 미리 고정함 |
| 2부 | 기관·세력 | 다빈 | 위험개체·신도·보유체라는 분류가 사람보다 먼저 옴 |
| 2부 | 엘리스 | 다빈 | 강자가 된 뒤에도 대신 결정하지 않는지 시험받음 |
| Rift Accord | 델타그린/비밀세계 전체 | 인류 | ‘생존을 위해 어디까지 관리·묵인할 수 있는가’로 확대 |

이 등뼈는 유지한다. 각 부의 사건을 새로 만들 때도 **같은 답을 반복하지 않고 위치와 힘의 관계를 바꾸어 변주**한다.

# 2. 전체 주요 사건 chronology + 구조 판정

## A. 제1~5화 — 출항, 금기지식, 경호 관계, 황색 침투, 선박 붕괴

### 원인
- 이안은 금기 고서와 접촉한다.
- 엘리스는 윌리엄이 정한 사람이 아니라 자신이 고른 경호원 주안과 출항한다.
- 황색은 카터 모녀·고서·관련 인물을 노리고 선박에 침투한다.

### 발전
- 평범한 호화 유람선이 빠르게 오컬트 재난으로 바뀐다.
- 엘리스의 `내가 고른 경호원`과 주안의 직업적 보호가 설치된다.
- 이안은 지식을 얻는 행위 자체가 자신을 위험과 연결한다는 사실을 체험한다.

### 결과
- 선박 붕괴와 분리.
- 각 인물의 초기 위치가 강제로 흔들린다.

### 구조 판정
- `KEEP`.
- Reader Promise와 장르 전환이 빠르다.
- 다만 이후 밀리의 첫 마도사 위상을 더 강하게 만들 계획이라면 초반 황색 마법 노출과 기능 중복을 재검토한다.

---

## B. 제6~10화 — 섬 생존, 밀리 재회, 배신, 이안의 첫 상실

### 원인
- 이안·엘리스는 생존하며 황색과 섬 세력을 탐색한다.
- 이안은 사라졌던 밀리를 다시 만난다.

### 발전
- 밀리는 실제 친구처럼 행동하면서 동시에 황색 측 목적을 가진다.
- 이안은 `친구라는 사실`과 `지금 믿어도 되는가`를 분리하기 시작한다.
- 제10화에서 밀리는 이안·엘리스를 강제로 제압하고 ‘필요한 사람/인질’로 다룬다.
- 이안은 밀리에게 총을 쏜다.
- 밀리는 시체를 남기지 않고 사라져 이안이 본체·분신·투영 여부를 모른다.

### 결과
- 최신 정본의 **밀리 첫 disappearance / death-misread** 기능으로 사용할 수 있는 강한 기반이 이미 있다.

### 판정
- 사건 기능 `KEEP`.
- 최신 정본에 맞춰 **이 사건은 밀리의 최종 죽음이 아니라 이안이 죽음으로 오인하는 첫 소실**로 명확히 관리한다.
- 이후 밀리가 살아 돌아왔을 때 이안이 겪는 감정과 판단 비용을 더 연결한다.

---

## C. 제11~18화 — 주안과 황색의 협력, 비야키, 희생 논리, 세실리아 추적, 주안 신체 이상, 엘리스 정신 경계

### 강점
- 제11화에서 주안은 `사람이 싸다는 말처럼 들립니다`라고 반응하고, 죽어가는 사람을 제물로 쓰는 황색 논리를 거부한다.
- 완전히 깨끗한 선택지가 없는 상황에서도 자신이 어떤 선을 넘지 않을지 기록한다.
- 엘리스는 정신 능력을 배우면서도 `힘이 주어졌다고 자동으로 내 것이 아니다. 쓰기로 고른 순간 책임이 생긴다`는 방향을 잡는다.

### P0 충돌 — 하템
현재 원고의 `히템`은:
- 초반부터 얼굴이 공개된 여성으로 등장하고,
- 황색과 거의 같은 실무 마도사처럼 행동하며,
- 제18화에는 이미 반쯤 죽은/비정상 신체 상태이고,
- 엘리스에게 직접 정신 기술까지 가르친다.

최신 정본은:
- 표기 `하템`.
- 평소 가면.
- 가면 아래 실제 얼굴 = 밀리가 변장에 사용한 얼굴.
- 황색 신도가 아니라 다른 신을 믿는 계약/용병 계열 외부자.
- 밀리와 상당 기간 동시에 살아 있어야 함.
- 이안이 처음에는 `밀리의 얼굴`로 보다가 하템 본인과 별도 관계를 형성해야 함.

### 판정
- 주안–황색 협력/희생 논리 장면은 `KEEP`.
- 하템의 신앙·소속·얼굴 노출 방식·엘리스 교습 기능은 `REWORK`.
- 하템이 엘리스에게 주는 정보 중 꼭 필요한 기능은 **하템 개인 능력/계약 범위로 재설계하거나 다른 인물과 분담**해야 한다.

## D. 제19~24화 — 이안의 관찰 규칙, 지도 침투, 팀 재결합, 주안 신체 반응 제어

### 강점

### 판정
- `KEEP` 중심.
- 최종 POV pass에서 과도한 장면 내 POV 왕복은 축소한다.

## E. 제25~30화 — 제3세력, 밀리 생존 확인, 거대 의식, 이안의 정신 붕괴와 현행 ‘히템 환각’

### 현재 기능
- 밀리가 살아 있었다는 것이 확인된다.
- 이안은 친구와 적이라는 모순을 동시에 유지해야 한다.
- 제28화에서 이안은 비현실적인 연구실에서 ‘히템’을 보고 그것이 자신의 환각임을 자각한다.
- 제29~30화에서 이안은 의식 연결 구조를 읽고 전력을 깨뜨리는 방식으로 싸운다.

### P0 충돌
최신 정본의 이안 arc는:

```text
밀리 배신
→ 밀리 첫 소실/죽음 오인
→ 가면 벗은 하템 = 밀리가 쓰던 얼굴
→ 밀리와 하템이 같은 얼굴로 동시에 살아 있음
→ 이안이 하템을 밀리와 분리해 인식
→ 하템 사망
→ 사후 하템 환각/환청
→ 밀리 최종 죽음
→ 두 상실이 한 얼굴에 겹침
→ [광기] 확립·진짜 마도사 각성
```

현재 제28화의 ‘히템 환각’은 **하템의 확정 사망 이전**에 너무 강하게 등장해, 최신 정본의 사후 환각 계약을 선점한다.

### 판정
- 제28화 `편안한 연구실 / 이안이 현실을 의심 / 자기 환각이 자기에게 말함`이라는 **장면 기능은 매우 강하므로 보존**한다.
- 다만 두 방법 중 하나로 재설계해야 한다.
  1. 이 시점의 존재를 하템의 chronic hallucination이 아닌 **외부 의식에 의해 생긴 급성 환각**으로 명확히 분류.
  2. 가장 강한 하템 환각 장면 자체를 하템 사망 뒤로 이동/재배치.
- 후자를 우선 검토한다. 최신 이안 arc와 `SETUP → RECONTEXTUALIZE`가 가장 강해진다.

## F. 제30~36화 — 쿠바라, 쇼거스, 주안의 괴물화/자기 선택, 협동 최종전

### 대표 하이라이트

#### 쿠바라
- 첫 몇 합만에 주안이 `못 이긴다`고 판단.
- 승리가 아니라 시간·위치 확보로 목표를 바꿈.
- 상대가 약해지지 않는다.

판정: **S / KEEP**.

#### 주안 uncontrolled body
- 팀이 주안의 몸을 멈추는 과정에서 ‘명령’보다 본인 선택을 되찾는 방향이 중요하다.
- `명령? → 부탁입니다. 제가 선택한 부탁.`은 주안 core의 강한 CHOICE_PROOF다.

판정: **SS 후보 / KEEP**.

#### 쇼거스
- 전장 전체가 몸.
- 본 공격을 학습.
- 주안·엘리스·이안·아킴이 서로 다른 역할로 같은 약점을 본다.
- 한 사람의 최종기보다 협동/규칙 파악으로 끝난다.

판정: **SS / KEEP**.

### P0 이안–밀리–하템 debt
- 이 구간 안 또는 직전/직후에 하템의 **독립 인격 관계 → 사망 → 이안 환각 시작**이 들어갈 자리와 원본 기능을 다시 찾아야 한다.
- 밀리 최종 죽음은 하템 사망 뒤여야 한다.
- 현재 원고는 이 순서가 화면에서 성립하지 않는다.

## G. 제37~42화 — 전후 협상, 가론, 윌리엄–엘리스 이념 대결, 가족 귀환

### 강점
- 제37화 가론은 명령 체계가 무너진 뒤 자신의 선택을 타인에게 넘기려는 습관을 보인다.
- 엘리스는 ‘승자가 명령하는 자리’ 대신 협상 테이블을 만든다.
- 제40화 윌리엄–엘리스 대화는 1부의 이념적 climax로서 강하다.
- 엘리스는 아버지를 사랑하면서도 죄와 선택을 별도로 본다.
- 가족 재회가 실제 행복으로 남는다. 윌리엄을 평면 악당으로 만들지 않는다.

### P0 라르고 노출 부채
최신 정본상 **라르고가 이 최종 협상에서 윌리엄 곁에 있어야 한다.**

필요한 연출:
- 독자에게는 ‘유능하지만 평범한 비서’.
- 다른 요원들의 과도한 경례/공포 없음.
- 이안은 방이 너무 `정돈/안정`되어 있다는 위화감.
- 주안은 이유 없이 비서의 위치를 체크하고 엘리스와 라르고 사이를 의식.
- 둘 다 윌리엄 탓이라고 생각할 수 있어야 함.
- 객관적 능력 증명 금지.

현재 제40화에는 라르고가 없다.

판정: **P0 REWORK / RESTORE**.

### P0 주안–엘리스/윌리엄 설계 seed 부채
현재 제40화의 윌리엄 갈등은 강하지만, 최신 연애 정본에 필요한
`윌리엄의 설계/개입이 주안 자신의 감정뿐 아니라 엘리스의 마음의 자율성까지 의심하게 만든다`는 근거가 충분히 설치되지 않는다.

판정: **P0 REWORK**.
- 윌리엄이 실제로 무엇을 설계했는지는 정본/원본 재확인 후 최소 범위로 표현.
- ‘엘리스의 사랑이 가짜였다’가 정답이 되면 안 된다.
- 불확실성 자체가 주안의 잘못된 회피를 낳아야 한다.

## H. 제43~44화 — 주안의 자발적 이탈, 미해결 연애, 8년 공백 시작

### 강점
현재 제43화는 주안이 이미 자기 호감을 인정한다.

- `좋아서 문제입니다.`
- 엘리스 옆에 있으면 원하는 답을 너무 쉽게 고를 것 같다고 말함.
- 몸/경호원 역할/자기 본성 중 무엇이 원인인지 확인하고 싶어 함.

이것은 최신 정본의
`처음부터 사랑한 것이 아니라 공동 생존 뒤 실제 호감이 생김`
과 호환된다.

### 필요한 재맥락화
최신 정본에서는 이후 주안의 문제를 한 단계 더 깊게 만든다.

```text
내 감정이 정말 내 것인가?
→ 엘리스 감정도 정말 그녀가 고른 것인가?
→ 객관적 완전한 증명은 없음
→ 주안은 엘리스의 반복된 선택을 믿지 못하는 오류에 빠짐
```

제43화는 현재 앞의 첫 질문만 강하다.

### P0 라르고 직접 충돌
제44화 현재 원고:
- 엘리스가 `라르고 휴빙`이라는 이름을 처음 듣는다.
- 윌리엄이 라르고를 `매우 강하다`고 직접 말한다.

최신 정본:
- 1부 라르고 = 윌리엄의 오래 본 평범하고 유능한 비서로 보임.
- 실제 강함은 공개 금지.
- `[규율]` first reveal = Rift Accord.

따라서 제44화의 이 부분은 **P0 REWORK**.

# 5. Rift Accord — 전체 작품의 최종 payoff 구조

권장 구조:

3. **관계 선택** — 초중반에 사과/고백/첫 제대로 된 관계 시작.
4. **정상회의/빈 의자/대균열 의제**.
5. **라르고 `[규율]` 첫 실제 공개** — `회의 중입니다.`
6. **Great Rift와 태평양 전선 진실**.
7. **관리된 묵인·냉전·Rift Accord의 도덕적 타협**.
8. **다음 시대** — 《뉴에이지 - 인간시대의 종언》.

## Juan–Alice 최종 payoff

반드시 순서:

```text
주안이 회피를 설명
→ 엘리스의 선택까지 의심했던 잘못을 인정
→ 사과
→ 완전한 객관적 증명은 없다고 인정
→ 그래도 현재 감정을 자기 선택으로 말함
→ 엘리스가 즉시 8년을 지워주지 않음
→ 두 사람이 동등한 관계를 처음 시작
```

핵심 문장:

> `당신 마음까지 의심해서 미안합니다.`

> `그래도 지금 내가 좋아한다고 말하는 건 내가 선택한 겁니다.`

엘리스의 반응 예:

> `그 말을 하는 데 8년이나 걸렸네요.`

이 장면은 ‘진짜 감정임이 과학적으로 증명됐다’가 아니라 **불확실성이 있어도 서로의 현재 선택을 인정한다**는 작품 주제 payoff다.

```text
A 즉시 안전/실무 → 기본 공유

```

Elliott는 이 계약을 의도적으로 위반하는 인물이다.
그는 `내가 너에게 필요한 정보만 정한다`고 믿는다.

Alice/Ian/Jumin은 서로 다른 방식으로 이 잘못에 대응한다.
