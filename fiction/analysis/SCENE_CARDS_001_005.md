## 제1화 · 위대한 심연의 군주

- 판정: `APPLY`
- 원본 핵심: 출항 → 브루스·데커·밀리 소개 → 짐 사고 → 고서 발견·제목 해독.
- 현재 통합 근거: EP1 S01/S02의 고서·펜던트 기능을 한 화 안에서 묶되, 브루스의 농담과 실제 경계를 함께 남긴다.
- 캐릭터 검수: 이안은 모르는 것을 모른다고 분리하고, 위험을 이해하려는 연구자 습관으로 고서를 받아든다.
- Canon 회귀: 폐기 설정·TRPG 시스템 문구를 새 설명축으로 복원하지 않는다.
- 상태 변화: 관광/연구 여행 → 고서가 이안을 인식하는 듯한 비정상 상태.
- 다음 압력: 엘리스가 직접 고른 경호원과 선내 일상으로 이동하면서 고서 반응이 다른 인물축과 연결된다.

## 제2화 · 내가 고른 경호원

- 판정: `APPLY`
- 원본 핵심: 엘리스·세실리아·데커의 오래된 인연, 주안·밀리 벌꿀주스, 엘리스가 사진으로 주안을 선택했다는 사실, 첫 경호 상호작용.
- 캐릭터 검수: 주안은 상급자 명령보다 현재 보호 대상자의 의사를 확인한다. 이는 `복종인자`가 아니라 현행 Canon의 선택·판단 전조다.
- 관계 기능: 엘리스는 아버지가 정한 여행에서 자신이 고른 작은 선택으로 주안을 받아들이고, 주안은 엘리스를 사람으로 먼저 본다.
- 후크: 이안 펜던트 반응 + 경호 통신 이상 + 노란 소매 반복.
- 다음 압력: 평범한 저녁이 침입 직전의 불안으로 전환된다.

## 제3화 · 식탁 아래의 축배

- 판정: `APPLY`
- 원본 교정 보존: 즐거운 식사 → 빈 테이블 → 엘리스 위험 감지 → 노란 코트 입장 → 주안·엘리스가 **함께 식탁 아래 은신** → 홀 전체 축배 → 공간 일렁임 → 비야키 현현 → 학살 → 탈출.
- POV 기능: `[엘리스] → [주안] → [엘리스]` 전환마다 감각/판단/정보가 추가되며 무표식 head-hopping을 사용하지 않는다.
- 주안 검수: 숨어 있을 이유와 사람을 구하러 나갈 이유를 분리해 판단한다. 엘리스에게도 `명령`이 아니라 `부탁`으로 수정한다.
- 호출기/신호기 계약: 엘리스가 누르면 주안 쪽 수신기에 진동이 오는 단순 비상 신호만 사용한다. GPS·문자·통화·위치표시는 없다.
- 다음 압력: 세실리아 확보 보고와 노란 코트의 직접 접촉.

## 제4화 · 카르코사의 낭독

- 판정: `APPLY`
- 원본 핵심: 주안의 선실 방어 → 브루고 제압 → 노란 코트와 대면 → 정신/인지 공격 → 엘리스의 보호 반응 → 주안이 이유를 다시 붙잡고 일어남 → 선체 붕괴.
- Canon 검수: 흰 방의 장면은 주안 본인도 `기억인지 / 상상인지 / 공격이 보여준 거짓인지` 확정하지 않는다. 이를 폐기된 독립 설정의 사실 증명으로 사용하지 않는다.
- 자기통제 핵심: 엘리스는 “내가 시켜서 말고”라고 이유를 돌려주고, 주안은 “당신이 싫어서”라고 자신의 현재 선택 이유를 말한다.
- 관계 기능: 엘리스가 주안 대신 결정을 내리는 장면이 아니라, 판단을 되찾도록 선택 공간을 돌려주는 장면으로 유지한다.
- 다음 압력: 네오 타이타닉호가 실제로 갈라진다.

## 제5화 · 신호기를 잃지 마세요

- 판정: `APPLY`
- 원본 핵심: 이안은 별도 황색 구조정 경로 / 주안·엘리스는 함께 이동하다 주안이 바다로 추락 / 탈론이 주안과 얽힘 / 거대한 파도에 주안·탈론 동시 휩쓸림 / 엘리스는 신호기를 지킴 / 해안에서 이안 발견 / 주안은 별도 감옥에서 각성하고 탈론도 별도 감옥에 있음.
- 사건 교정: 이안이 침몰 직전 주안·엘리스와 같은 갑판에서 재회하는 구 편성을 복원하지 않는다.
- 장치 검수: 신호기는 단순 신호 계약을 유지한다.
- 종료 상태: 엘리스+이안 해안 / 주안+탈론 별도 감옥 경로.
- 다음 저장소 파일은 아직 새 편성의 다음 회차가 아니다.

## 경계 검수

- `제1→2화`: 고서의 비정상 반응 → 엘리스·주안 일상·관계에서 펜던트 반응으로 연결.
- `제2→3화`: 노란 소매·통신 이상 → 식당의 노란 코트 공식 진입.
- `제3→4화`: 세실리아 확보·주안 신호 → 브루고/노란 코트 직접 대면.
- `제4→5화`: 선체 균열 → 침몰·분리·섬 진입.
- `제5→legacy-tail`: **정본 마이그레이션 경계.** 저장소의 구 제6화 「평생의 과제」는 새 제5화의 다음 사건으로 간주하지 않는다. 제006~010 최신 외부본을 다음 reconciliation 묶음으로 적용하기 전까지 이 경계의 연속성은 `NOT_YET_CLAIMED`다.
