# Scene Cards — 제001~005화 외부 최신본 Canon Reconciliation

갱신: 2026-08-10

## 제1화 · 위대한 심연의 군주

- 판정: `APPLY`
- 출항·짐 사고·고서 발견/해독과 브루스·펜던트 기능을 현재 source order 안에서 압축한다.
- 이안은 모르는 것을 확정하지 않고 위험을 이해하려는 선택으로 고서를 받아든다.

## 제2화 · 내가 고른 경호원

- 판정: `APPLY`
- 엘리스의 직접 선택, 벌꿀주스, 세실리아·데커의 오래된 인연, 경호/통신 이상을 결합한다.
- 주안은 보호 대상자의 의사를 현재 판단의 입력으로 먼저 확인한다.

## 제3화 · 식탁 아래의 축배

- 판정: `APPLY`
- 식사 → 빈 테이블 → 위험 감지 → 식탁 아래 공동 은신 → 축배 → 비인간 현현 → 탈출 순서를 유지한다.
- 신호 장치는 버튼 송신과 주안 쪽 진동 수신만 담당한다.

## 제4화 · 카르코사의 낭독

- 판정: `APPLY`
- 선실 방어·브루고·노란 코트·정신 압박·선체 붕괴를 잇는다.
- 흰 방 이미지는 기억/상상/공격이 만든 거짓 중 하나로 현 시점에 확정하지 않는다.
- 엘리스는 주안 대신 결론을 내리지 않고 현재 이유를 다시 붙잡을 공간을 돌려준다.

## 제5화 · 신호기를 잃지 마세요

- 판정: `APPLY`
- 침몰 때 이안의 구조 경로와 주안·탈론 분리 경로를 구분한다.
- 엘리스·이안은 해안, 주안은 별도 감옥으로 끝난다.
- 제6화 reconciliation 완료 뒤 이 종료 상태가 제6화 첫 상태와 정상 연결된다.

## 경계 검수

### 제1→2화
고서의 비정상 반응이 엘리스·주안 관계축과 펜던트 반응으로 이어진다.

### 제2→3화
노란 소매·통신 이상이 식당 침입의 직접 전조가 된다.

### 제3→4화
세실리아 확보·주안 신호가 브루고/노란 코트 직접 대면으로 넘어간다.

### 제4→5화
선체 균열이 침몰·분리·섬 진입으로 이어진다.

### 제5→6화
`VALIDATED CURRENT CONTINUITY`. 제5화의 엘리스·이안 해안 / 주안 감옥 종료가 제6화 `따뜻한 피난처`의 시작으로 직접 이어진다. 이전 migration boundary는 제10→legacy-tail로 이동했다.

## 역사 증거

이 파일은 제6~10 reconciliation 이후 현재 경계 상태를 반영한 001~005 scene-card owner다. 이전 카드의 제5→legacy-tail 판단은 당시 prefix=5 상태의 역사 증거로만 남긴다.
