# Canon·연속성 기준

## 상태 추적 차원

날짜·시간·이동, 인물 외형·능력·부상, 관계·약속·비밀·감정, 인물별 지식과 오해, 소지품·증거·문서, 장소 구조와 출입, 세계 규칙·비용·예외, 사건 원인·결과·목격자, POV·호칭, 복선·회수를 추적한다.

## 주요 고정 사항

- 호출기: 엘리스 송신기 / 주안 수신기. 일방향 비상 호출이며 GPS·문자·음성이 없다.
- 엘리스의 보호 자아: 외부 존재가 아니라 같은 자아의 보호적 부분이며 장기적으로 협업·통합한다.
- 히템: 선박에서 육체가 있는 상태로 등장하고 주안·이안·엘리스와 직접 대화한다.
- EP2 식당: 노란 코트의 사내는 합석하지 않으며 홀 전체에 축배를 든 뒤 비야키와 학살이 발생한다.
- EP2 종료: 주안과 탈론이 함께 파도에 휩쓸리고 이안·엘리스는 해안에서 합류한다.
- 제5~11화 시간선: 제5화의 황색 승선·데커 교전과 제6화 식당은 병행한다. 제6화는 복도 첫 총성 이전, 제7~8화는 직접 연속, 제9화는 같은 시각 세실리아 납치, 제10~11화는 직접 연속이다.
- 제10화 종료 상태: 엘리스·주안은 세실리아가 서쪽 복도로 이동했다는 정보만 알며 실제 납치는 모른다. 주안의 뺨 상처·흰 방 잔향·비정상적 힘과 엘리스의 보호 반응이 남는다.
- 주안 자기통제: 위협·명령·보호 자극에 몸이 먼저 반응할 수 있어도 `반응 → 멈춤 → 이유 → 선택`으로 자신의 결정을 회수한다. 엘리스와의 관계는 명령·복종 관계로 단순화하지 않는다.
- 1부 결말 순서: 쇼거스전 → 정치 협상 → 엘리스·윌리엄 대면 → 세실리아 회복 → 주안이 타인의 보호·명령 논리와 자신의 선택을 분리함 → 황색 이탈 → 응답 없는 호출기.

## 2부 기능 재배치

- 외부 전투·압박: 황색 과격파·외부 용병
- 추적·퇴로·후송: 경찰·의료진·라르고 팀
- 시간 측정 장비: 미스캐토닉 압수 장비와 델타그린·경찰·의료진 공동 관리
- 최종 선택: 다빈·주민·엘리스
- 원격 지원: 라르고, 이안, 주안·아킴. 현장 결말 결정권을 대신하지 않는다.
- 아킴: 등장 가능. 외부 사선·현장 지원은 가능하지만 다빈·주민·엘리스의 중앙 선택을 대체하지 않는다.
- 2부 제외 인물축: 버실라/바실라/Versilla/Woff의 직접 등장·개인 서사·독립 전투·기능 복원은 사용하지 않는다. 필요한 기능은 현행 주연·조연·단역 안에서 재판정한다.
